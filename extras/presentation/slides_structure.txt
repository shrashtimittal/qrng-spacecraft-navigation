Slide 2 — Why QRNG for Space Navigation?
--------------------------------------------
Key message:
    Randomness affects every navigation system — sensors, propagation, drift.
    Using quantum randomness gives more realistic stochastic modeling.

Points:
    • Spacecraft sensors suffer from noise + drift
    • GNSS outages cause uncertainty spikes
    • QRNG enables “physically true” randomness
    • Model behavior under real-world uncertainty

Visual suggestion:
    Noise distributions / QRNG concept diagram

Components:

    • QRNG wrapper (ANU → OS → PRNG fallback)

    • Streamlit UI for real-time visualization

Diagram suggestion:
    Orbit → QRNG noise → Measurement → Kalman Filter → Estimated Orbit


--------------------------------------------
Slide 4 — Simulation Flow
--------------------------------------------
Steps:
    1) Generate clean orbit (circular)
    2) Request quantum bits (ANU QRNG API)
    3) Convert bits → uniform → Gaussian noise
    4) Add drift + measurement noise
    5) Run Kalman filter
    6) Plot trajectory + RMSE

Visual suggestion:
    Flowchart or linear pipeline arrows
